# PokéSurvivor English Edition

An independent English-only adaptation of JPTER78/pokesurvivor, based on upstream commit `89ee17ad60f0c9ccb516fc026b93d3c5e3f9f1f0`.

## Included

- Original combat, enemy spawning, terrain, bosses, legendary rifts, move evolutions, items, gacha, collection and progression.
- English locked independently of browser language or saved language preference.
- English startup page, interface, help pages, manifest and number formatting.
- Additional translations for personality traits, level labels and search.
- Independent local profile saves and settings, using the `pse.` storage namespace.
- Full original sprite collection, original license and artist credits.

## Current service status

Local single-player works. Create a local profile to preserve progress in the same browser; guest progress is not saved. Clearing browser site data removes local saves. Existing saves from the original website are not imported.

Cloud accounts, Google sign-in, friends, online leaderboards and co-op require a separately owned Firebase project and, when needed, TURN service. Their original implementation remains in the source. `js/core/firebase-config.js` intentionally contains no upstream service configuration. Do not reuse the original author's services or copy deployment IDs from the upstream server documentation.

This edition has no donation destination. The original author is credited, not represented as the operator of this edition.

## Build

Requires Node.js and access to the npm registry for Terser when building:

```sh
node tools/build.js
node tools/verify-edition.cjs
node tools/prepare-dist.cjs
```

Serve `dist/` with any static HTTP server. `dev.html` is the editable source of the game page; `index.html`, `js/app.min.js` and `version.json` are generated by the original bundler. English reference pages under `en/` are editable HTML. The inherited bilingual SEO generator is an upstream reference, not part of this edition's build, since it would regenerate Spanish routes and upstream branding.

The hosting manifest declares `dist/` as the public directory. Server configuration, tooling, development documents and Spanish reference pages are not included in the public distribution.

## Validation

- All 66 game scripts parse.
- English is enforced even with a Spanish browser and saved Spanish preference.
- Local profile registration, login, currency/collection/upgrade persistence and guest isolation pass the automated checks.
- Original gameplay engine files were compared with upstream; combat, entities, world and gameplay systems are unchanged.
- Browser checks cover entry, all eight personality questions, partner selection, upgrades, game start, movement, automatic attacks and pause. Online multiplayer has not been tested because no independent cloud services are configured.
